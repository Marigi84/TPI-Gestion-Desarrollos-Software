# Guía Rápida – Solicitud de Certificados Académicos

## ¿Qué certificados puedo solicitar?

Desde el SGCA podés solicitar:

- Certificado de alumno regular.
- Certificado analítico parcial.

## ¿Cómo solicitar un certificado?

1. Ingresá al portal del SGCA.
2. Seleccioná el tipo de certificado que necesitás.
3. Confirmá la solicitud.
4. El sistema verificará automáticamente si cumplís las condiciones necesarias para emitirlo.
5. Si la solicitud es aprobada, el certificado se generará en formato PDF.
6. Podrás descargarlo desde el portal.
7. También recibirás un correo electrónico con un link de descarga.

## ¿Qué pasa si tengo una deuda administrativa?

Si el sistema detecta una deuda administrativa, el certificado no será emitido y se mostrará el motivo del rechazo.

## ¿Qué pasa si ocurre un error?

Si el sistema no puede procesar la solicitud en ese momento, se mostrará un mensaje indicando que intentes nuevamente más tarde.

Si el certificado fue generado pero falla el envío del correo, seguirá disponible para descargar desde el portal.

## Certificado analítico parcial

El analítico parcial incluye las materias correspondientes y sus calificaciones en escala de 1 a 10. Las materias extracurriculares no se incluyen.

---

**Importante:** verificá que tus datos académicos y administrativos estén actualizados antes de realizar la solicitud.
